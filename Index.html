How it works (standard method)

  • Your dice rolls are treated as a base‑6 number (1→0, 2→1, …, 6→5).
  • This number is converted to bytes and truncated to the required entropy length (128–256 bits).
  • A BIP39 checksum (SHA‑256) is appended and the result is mapped to words.
  • Compatible: The same rolls produce the same seed as other standard BIP39 dice tools.
  • No data leaves your device. This file contains no external scripts or network calls.
